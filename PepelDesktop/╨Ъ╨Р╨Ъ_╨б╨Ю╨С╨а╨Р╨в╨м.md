# Пепел войны как приложение (Windows / Mac / Linux)

## Способ 1. Бесплатная сборка на GitHub (ничего ставить не нужно)
1. Создай аккаунт на github.com и новый репозиторий.
2. Загрузи в него всё содержимое этой папки (включая скрытую `.github`).
3. Вкладка **Actions → Build desktop apps → Run workflow**.
4. Через 5–10 минут внутри запуска появятся архивы для Windows (установщик `.exe` и portable), Mac (`.dmg`) и Linux (`.AppImage`).

## Способ 2. Локально (нужен Node.js 20+)
    npm install
    npm start            # запустить игру
    npm run start:ctf    # запустить CTF-версию
    npm run dist         # собрать установщик под свою ОС

Окно: F11 — полный экран. Сохранения лежат в профиле приложения и не стираются при обновлении.

## Какая игра в сборке
Установщик собирает обе версии в одном приложении. Для раздачи участникам CTF можно
запустить `npm run start:ctf`, а при сборке задать PEPEL_GAME=ctf или удалить папку `app/main` (тогда запускается CTF автоматически).
