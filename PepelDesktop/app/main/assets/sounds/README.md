# Свои звуки для «Пепла войны»

Есть два способа подставить свои звуки и музыку.

## 1. Через игру (проще всего)
**Настройки → Звуки (свои файлы)**: у каждого события есть кнопки ▶ (проверить), «Файл» (выбрать свой) и «Сброс». Файлы сохраняются в браузере (IndexedDB).

## 2. Через папку
Положи файл в эту папку с именем `<id>.ogg` (или `.mp3`, `.wav`, `.m4a`). Игру нужно открывать через локальный сервер (`python3 -m http.server`), а не двойным кликом по файлу.
Можно также создать `manifest.json`: `{"swing": "my_sword.ogg"}`.

Приоритет: файл из меню > файл из папки > встроенный синтезатор.
